# 中国天气查询（weather）

一个常驻 DSH 的天气工具：查询中国境内（含港澳台）的实时天气、空气质量与 1–7 天预报。

- **零费用**：全部使用免费、无需 API 密钥的公开服务，没有注册、没有额度、没有账单。
- **自动定位**：不传地区时，按本机公网 IP 定位（优先中文源 ipip.net，坐标由 Photon 解析）。
- **指定地区**：支持城市、区县、新区，例如“杭州”“北京市朝阳区”“上海市浦东新区”“乌鲁木齐”“湖北省天门市”。
- **仅限中国境内**：境外地区会直接报错，不会返回国外天气。

## 安装

直接用 DSH 的插件安装命令：

```bash
dsh plugin add https://github.com/YEHO-gg/dsh-china-weather
```

或者手工 link（开发调试用）：

```bash
cd %USERPROFILE%\.dsh\profiles\desktop
pnpm add link:<本仓库路径>
```

然后在 profile 的 `package.json` → `dsh.profile.bundles` 里加上 `"dsh-china-weather"`，重启 DSH。

> 本插件不需要任何 API 密钥，不需要配置文件。

## 在对话里怎么用

直接说“查一下天气”“杭州明天会下雨吗”“北京朝阳区现在多少度”即可，模型会自动调用 `weather` 工具。

也可以显式调用：

```json
{ "location": "杭州", "days": 3 }
```

`days` 取 1–7，默认 3；省略 `location` 即自动定位。

## 数据来源

| 用途 | 服务 | 说明 |
|---|---|---|
| 天气、空气质量 | Open-Meteo | 免费、免密钥，ECMWF/ICON 等模式 |
| 地名解析 | Photon（OpenStreetMap） | 免费、免密钥，支持中国区县/新区 |
| IP 省市 | ipip.net | 免费接口，中文省市名更贴近国内 IP |
| IP 坐标 | ipwho.is | 免费、免密钥，提供经纬度兜底 |

结果缓存 10 分钟，避免重复请求。

## 输出内容

当前天气（气温、体感、湿度、降水、风向风速）、空气质量 AQI/PM2.5/PM10、逐日预报（最高/最低温、降水概率、日出日落、紫外线）以及数据来源说明。

## 已知限制

- IP 定位到城市级，可能与实际位置存在偏差；需要更精确时请直接给地区名。
- 区县名存在同名时（如“朝阳区”），按 Photon 的相关度取首个匹配；建议带上城市名。
- 天气为网格预报，不等同于官方气象台逐小时实况。

## 开发

- `index.js`：工具注册（名称、描述、参数、输出 schema、渲染）。
- `weather.js`：定位、地名解析、天气与空气质量请求、中文摘要渲染。
- `selftest.mjs`：本地自测脚本（`node selftest.mjs`）。
